# ☁️ Cloud-Based Online Quiz Examination

## 📌 Project Overview

The **Cloud-Based Online Quiz Examination System** is a web-based application designed to conduct online multiple-choice examinations. Students can enter their name, attend the quiz within a given time, submit their answers, and receive their results instantly.

The system uses **Python Flask** for the backend and **HTML, CSS, JavaScript, and SQLite** for the frontend and data management.

## 🎯 Objectives

* Conduct examinations online.
* Provide a simple and user-friendly interface.
* Display multiple-choice questions.
* Provide a countdown timer.
* Automatically evaluate answers.
* Calculate and display the student's score.
* Reduce manual examination and evaluation work.
* Provide a foundation for cloud deployment.

## 🚀 Features

* Student name entry
* Online MCQ examination
* Countdown timer

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/cloud-online-quiz.git
```

### 2. Open the Project

```bash
cd cloud-online-quiz
```

### 3. Install Flask

```bash
python -m pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

Open:

```text
http://127.0.0.1:5000
```

## 📝 How to Use

1. Open the application.
2. Enter the student's name.
3. Click **Start Examination**.
4. Answer the multiple-choice questions.
5. Complete the exam before the timer ends.
6. Click **Submit Examination**.
7. The system automatically checks the answers.
8. The final score and percentage are displayed.

## ☁️ Cloud-Based Concept

The application can be deployed on a cloud platform so that students can access the examination through the internet. The backend handles requests, processes answers, and generates examination results.

In a larger implementation, cloud database services can be used to store student information, questions, answers, and examination results.
